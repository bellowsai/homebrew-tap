# Bellows for Homebrew

```sh
brew install --cask bellowsai/tap/bellows
```

[Bellows](https://bellowsai.app) is a desktop workspace for coding agents: Claude Code, Codex, Gemini CLI, any agent that speaks the Agent Client Protocol, or a local model, with a permission prompt for every change, a hash-linked audit trail, and live session sharing. The desktop app is free.

The cask installs the Apple-silicon build from the [GitHub release](https://github.com/bellowsai/bellows-releases/releases). Bellows tells you when a new version is out; `brew upgrade --cask bellows` installs it.
